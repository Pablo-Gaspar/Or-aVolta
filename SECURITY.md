# Política de segurança

Este é um projeto em estágio de documentação/protótipo; não coloque dados reais de clientes nele.

## Reportar vulnerabilidade
Não abra Issue pública com exploit, credencial ou PII. Até existir canal privado formal para o projeto, contate os mantenedores diretamente pelo mecanismo privado do repositório GitHub e forneça passos mínimos de reprodução sem dados reais.

Não tente acessar dados de outras organizações, fazer testes de carga em produção ou explorar serviços sem autorização. Credenciais encontradas devem ser revogadas/rotacionadas, não copiadas para Issues ou logs.

## Compromissos antes de piloto
Antes de aceitar dados reais, definir canal de reporte, responsáveis e janela de resposta, processo de incidente, gestão de dependências, política de backup/retention, escopo de ambientes e plano de correção. Esta política não constitui certificação ou declaração de conformidade.
